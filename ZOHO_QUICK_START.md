# 🚀 Быстрый старт: Импорт агентов в Zoho CRM

## 📋 Что происходит после импорта

### 1. Агенты → Контакты
- ✅ Все агенты создаются как **контакты** в модуле **Contacts**
- ✅ Данные из CSV импортируются автоматически
- ✅ Agent ID сохраняется в Description или кастомном поле

### 2. Доступность данных
- ✅ Агенты видны в списке контактов
- ✅ Можно искать по имени, Agent ID, Extension
- ✅ Можно фильтровать по Department, Status

## 🎯 Как "активировать" агентов

### ⚠️ Важно: Два типа активации

#### В Tikal (Call Center):
```python
# Логин агента
client.agents.login(agent_id='6701', ag_exten='2012')

# Установка статуса
client.agents.set_state(agent_id='6701', state='ready')
```

#### В Zoho CRM:
1. **Через статус:** Добавьте кастомное поле "Status" → установите "Active"
2. **Через теги:** Создайте группу "Active Agents" → добавьте агентов
3. **Через чекбокс:** Создайте поле "Is Active" → отметьте активных

## 💼 Что могут делать агенты в Zoho

### В модуле Contacts:
- ✅ Просмотр информации (имя, телефон, статус, очереди)
- ✅ Поиск и фильтрация
- ✅ Организация (группы, теги)
- ✅ Отчеты и аналитика

### В других модулях:
- 📞 **Calls** - связь звонков с агентами (требует настройки)
- 📊 **Reports** - отчеты по производительности
- 🔗 **Custom Modules** - связь с лидами/сделками
- 📧 **Email** - отправка уведомлений

## 🔌 Модули интеграции

### Текущая интеграция (односторонняя):
```
Tikal API → CSV Export → Zoho Contacts
```

**Работает в:**
- ✅ **Contacts** - основной модуль
- ✅ **Reports** - отчеты
- ⚠️ **Calls** - требует настройки
- ⚠️ **Custom Modules** - требуют создания

### Потенциальная интеграция (двусторонняя):
```
Tikal API ←→ Zoho API (требует разработки)
```

**Может работать в:**
- ✅ **Contacts** - синхронизация
- ✅ **Calls** - синхронизация звонков
- ✅ **Leads** - связь лидов с агентами
- ✅ **Deals** - связь сделок
- ✅ **Tasks** - назначение задач
- ✅ **Workflow Rules** - автоматизация

## 📝 Быстрая настройка

### Шаг 1: Импорт
```bash
python get_active_agents_only.py
# Импортируйте CSV в Zoho: Contacts → Import
```

### Шаг 2: Создание кастомных полей
1. Settings → Customization → Modules → Contacts
2. Создайте поля:
   - **Agent ID** (Text)
   - **Extension** (Text)
   - **Tikal Status** (Picklist)
   - **Queues** (Multi-Select)
   - **Is Active** (Checkbox)

### Шаг 3: Настройка фильтров
- Contacts → Filter → Is Active = True
- Создайте группу "Active Agents"

### Шаг 4: Отчеты
- Reports → Create Report → Contacts
- Group by: Department, Status, Queues

## 🔄 Регулярное обновление

```bash
# Ежедневно
python get_active_agents_only.py
# Импортируйте обновленный CSV
```
