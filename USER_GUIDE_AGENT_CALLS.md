# 📞 Руководство для Агента: Создание звонков из Zoho CRM

## ✅ Да, вы можете создавать звонки из Zoho!

После настройки администратором вы сможете создавать звонки напрямую из Zoho CRM через систему Tikal.

---

## 🎯 Как создать звонок

### Способ 1: Через кнопку в контакте

1. **Откройте контакт** в Zoho CRM (модуль Contacts)
2. Найдите кнопку **"Позвонить"** или **"Call via Tikal"** (настроена администратором)
3. **Нажмите на кнопку**
4. Звонок будет создан автоматически
5. Вы получите звонок в системе Tikal

### Способ 2: Через форму

1. Откройте контакт
2. Найдите поле **"Phone"** или **"Mobile"**
3. Рядом может быть кнопка для звонка
4. Нажмите на кнопку

---

## ⚠️ Требования

Для создания звонка необходимо:

1. ✅ **Agent ID заполнен** в контакте
   - Должен совпадать с вашим Agent ID в системе Tikal
   - Проверьте в карточке контакта

2. ✅ **Номер телефона заполнен**
   - Поле **Phone** или **Mobile** должно содержать номер
   - Номер будет очищен автоматически (удалятся пробелы, дефисы и т.д.)

3. ✅ **Вы онлайн в системе Tikal**
   - Убедитесь, что вы залогинены в Tikal
   - Статус должен быть "Online" или "Ready"

---

## 🔍 Проверка перед звонком

### Перед созданием звонка проверьте:

1. **Откройте контакт** в Zoho CRM
2. **Проверьте поля:**
   - Agent ID = ваш ID (например, `6701`)
   - Phone = номер для звонка (например, `0508155492`)
3. **Проверьте статус в Tikal:**
   - Вы должны быть онлайн
   - Статус: Online, Ready или аналогичный

## 📞 Пример использования

### Пример 1: Звонок клиенту

1. Откройте контакт клиента в Zoho CRM
2. Убедитесь, что:
   - В контакте указан ваш Agent ID
   - Заполнен номер телефона клиента
3. Нажмите кнопку **"Позвонить"**
4. Звонок создан! Ответьте на звонок в системе Tikal

1. В модуле Contacts найдите нужный контакт
2. Откройте контакт
3. Нажмите кнопку **"Позвонить"**
4. Готово!

## ⚠️ Что делать, если не работает

### Проблема: Кнопка не видна

**Решение:**
- Обратитесь к администратору
- Возможно, кнопка еще не настроена
- Или у вас нет прав на использование функции

### Проблема: "Agent ID не найден"

**Решение:**
- Проверьте, что в контакте заполнен Agent ID
- Убедитесь, что Agent ID совпадает с вашим ID в Tikal
- Обратитесь к администратору для проверки данных

### Проблема: "Номер телефона не указан"

**Решение:**
- Заполните поле Phone или Mobile в контакте
- Убедитесь, что номер указан правильно
- Попросите администратора обновить данные контакта

### Проблема: "Звонок не создается"

**Решение:**
1. Проверьте, что вы онлайн в Tikal
2. Проверьте Agent ID и номер телефона
3. Обратитесь к администратору для проверки настроек
