## 🔄 Типичные сценарии

### Сценарий 1: Первый импорт агентов

1. Запустите: `python get_active_agents_only.py`
2. Откройте Zoho CRM → Contacts → Import
3. Загрузите созданный CSV файл
4. Сопоставьте поля (Agent ID, Extension, Status и т.д.)
5. Нажмите Import

**Готово!** 146 агентов импортированы в Zoho CRM.

---

### Сценарий 2: Обновление данных

1. Запустите: `python get_active_agents_only.py`
2. Запустите: `python prepare_zoho_import.py`
3. Zoho CRM → Contacts → Import
4. Загрузите новый CSV
5. Выберите: **"Update existing records"**
6. Import

**Готово!** Данные агентов обновлены.

---

### Сценарий 3: Поиск агента в Zoho

1. Откройте Zoho CRM → Contacts
2. Используйте поиск:
   - Введите Agent ID (например, `6701`)
   - Или используйте фильтр: Filter By Fields → Agent ID
3. Откройте найденный контакт

## 🛠️ Работа с API

### Получить данные из Tikal:

```python
from tikal_client.tikal_client_v2 import TikalClientV2
from config import TIKAL_CONFIG

client = TikalClientV2(
    base_url=TIKAL_CONFIG['base_url'],
    api_key=TIKAL_CONFIG['api_key']
)

# Получить статус агента
result = client.agents.get_state('6701')
print(result)

client.close()
```

### Получить данные из Zoho:

```python
import requests
from config import ZOHO_CONFIG

url = f"{ZOHO_CONFIG['api_domain']}/crm/v2/Contacts"
headers = {
    "Authorization": f"Zoho-oauthtoken {ZOHO_CONFIG['access_token']}"
}

response = requests.get(url, headers=headers)
contacts = response.json()
print(contacts)
```

**См. примеры:** `example_v2.py`, `example_working.py`
