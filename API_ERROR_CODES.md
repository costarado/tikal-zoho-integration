# Коды ошибок Tikal API

На основе ответов API, вот основные коды ошибок:

## Коды статусов

### Успешные операции
- **200** - O.K. - Операция выполнена успешно

### Ошибки параметров

- **101** - Missing parameter - Отсутствует обязательный параметр
  - Пример: `agent_login` требует `ag_exten`
  - Пример: `call_get_cdr` требует `unique_id`
  - Пример: `call_originate` требует `dest_num`

- **102** - Invalid parameter: only digits are allowed - Параметр должен содержать только цифры
  - Пример: `department` должен быть числом, а не строкой

- **103** - Invalid parameter: use only alphabet characters, hyphens or spaces - Параметр должен содержать только буквы, дефисы или пробелы
  - Пример: `name` агента не может содержать подчеркивания или цифры

### Ошибки данных

- **205** - The agent id supplied does not exist - Агент с указанным ID не существует
  - Используйте существующий ID агента

- **210** - License limit for agents number has been reached - Достигнут лимит лицензии на количество агентов
  - Невозможно создать нового агента - лимит лицензии исчерпан
  - Нужно удалить существующего агента или обновить лицензию

- **224** - A queue with the supplied id already exits - Очередь с указанным ID уже существует
  - Используйте другой ID для очереди или удалите существующую

## Структура ответа API

Все ответы имеют структуру:

```json
{
  "data": {
    "request": {
      "request_id": "1767610940.6142",
      "type": "agent_create",
      "format": "json",
      // ... параметры запроса
    },
    "status": {
      "code": "200",
      "description": "O.K.",
      "field_name": "NONE"
    },
    "info": {
      // Дополнительная информация (если есть)
    }
  }
}
```

## Правила валидации

### Имя агента (name)
- ✅ Разрешено: буквы, дефисы (-), пробелы
- ❌ Запрещено: подчеркивания (_), цифры, специальные символы
- Примеры:
  - ✅ `"bisly agent"`
  - ✅ `"John-Doe"`
  - ❌ `"bisly_agent"` (подчеркивание)
  - ❌ `"agent123"` (цифры)

### Отдел (department)
- ✅ Только цифры
- ❌ Не строка
- Примеры:
  - ✅ `department=1`
  - ✅ `department=123`
  - ❌ `department="Sales"` (строка)

### Параметры методов

#### agent_login
- Обязательные: `id`, `ag_exten` (extension агента)

#### call_originate
- Обязательные: `agent_id`, `dest_num` (не `phone_number`!)
- **Важно**: `dest_num` должен содержать **ТОЛЬКО ЦИФРЫ** (без +, пробелов, дефисов)
  - ✅ Правильно: `'0508155492'`, `'1234567890'`
  - ❌ Неправильно: `'+1234567890'`, `'123-456-7890'`, `'123 456 7890'`

#### call_get_cdr
- Обязательные: `unique_id` (уникальный ID звонка)

## Рекомендации

1. **Проверяйте статус ответа** перед использованием данных
2. **Используйте существующие ID** для операций с агентами/очередями
3. **Следуйте правилам валидации** для параметров
4. **Используйте правильные имена параметров** из документации
