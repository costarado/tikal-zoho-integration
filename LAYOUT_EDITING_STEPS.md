# 📝 Пошаговая инструкция: Редактирование макетов в Zoho CRM

## 🎯 Цель

Добавить кастомные поля во все макеты модуля Contacts.

---

## 🚀 Шаг 1: Открытие редактора макетов

1. Войдите в **Zoho CRM**
2. **Settings** (⚙️) → **Customization** → **Modules**
3. Найдите **"Contacts"** в списке модулей
4. **Кликните на "Contacts"**
5. Перейдите на вкладку **"Layouts"** (Макеты)

**Важно:** НЕ "Public Views", а именно **"Layouts"**!

---

## 🚀 Шаг 2: Выбор макета для редактирования

### Вариант A: Редактировать существующий макет "Standard"

1. Найдите макет **"Standard"** в списке
2. **Кликните на "Standard"** (один клик)
3. Должна открыться страница макета
4. Нажмите кнопку **"Edit"** (вверху справа)

### Вариант B: Клонировать макет (если нужно)

1. Найдите макет **"Standard"**
2. **Наведите курсор** на "Standard"
3. Справа появится иконка **"⋮"** (три точки)
4. **Кликните на иконку** → **"Clone"**
5. Введите имя: **"Standard - Tikal"**
6. **Save**

---

## 🚀 Шаг 3: Добавление полей в макет

После нажатия "Edit" откроется редактор макетов:

### 3.1. Выберите вкладку

Вверху редактора есть вкладки:
- **"CREATE"** - форма создания контакта
- **"QUICK CREATE"** - быстрая форма создания
- **"DETAIL VIEW"** - форма просмотра контакта

**Начните с "DETAIL VIEW"** (просмотр контакта)

### 3.2. Найдите список полей

Справа в редакторе должен быть список полей:
- Может быть раздел **"Unused Fields"** (Неиспользуемые поля)
- Или просто список всех полей

### 3.3. Найдите кастомные поля

В списке найдите:
- **Agent ID** (или Agent_ID)
- **Extension**
- **Tikal Status**
- **Queues**
- **Queue Count** (или Queue_Count1)
- **Active**

### 3.4. Перетащите поля в форму

1. **Зажмите левой кнопкой мыши** на поле (например, "Agent ID")
2. **Перетащите** в нужную секцию формы (слева)
3. **Отпустите кнопку мыши**

Повторите для всех 6 полей.

### 3.5. Создайте секцию (опционально)

Для лучшей организации:

1. В форме найдите кнопку **"NEW SECTION"** (Новая секция)
2. **Кликните** → введите имя: **"Agent Information"**
3. **Перетащите все кастомные поля** в эту секцию

---

## 🚀 Шаг 4: Сохранение изменений

1. После добавления всех полей
2. Нажмите **"Save"** или **"Save and Close"** (вверху справа)
3. Изменения сохранятся

---

## 🚀 Шаг 5: Повторение для других макетов

Повторите шаги 2-4 для:

1. **"Create Contact"** - вкладка "CREATE"
2. **"Detail View"** - вкладка "DETAIL VIEW" (уже сделано)
3. **"Edit Contact"** - вкладка "QUICK CREATE" или "EDIT"

---

## 📋 Визуальная схема

```
Settings → Customization → Modules → Contacts → Layouts
                                                      ↓
                                              [Список макетов]
                                                      ↓
                                              [Standard] → Edit
                                                      ↓
                                    [Редактор макетов]
                                    ┌─────────────────┐
                                    │  [CREATE]       │
                                    │  [QUICK CREATE] │
                                    │  [DETAIL VIEW] ← Начните здесь
                                    └─────────────────┘
                                    ┌─────────────────┐
                                    │  Форма (слева)  │
                                    │  [Секции]        │
                                    │  [Поля]          │
                                    └─────────────────┘
                                    ┌─────────────────┐
                                    │  Список полей   │
                                    │  (справа)       │
                                    │  - Agent ID     │
                                    │  - Extension    │
                                    │  - ...          │
                                    └─────────────────┘
                                    Перетащите поля → в форму
```

---

## ⚠️ Важные моменты

1. **"Public View"** - это НЕ то же самое, что "Layouts"
   - "Public View" - для публичного доступа
   - "Layouts" - для редактирования форм

2. **Поля должны быть созданы** перед добавлением в макет
   - Если полей нет в списке - создайте их сначала
   - Settings → Fields → Add Fields

3. **Перетаскивание работает только в режиме редактирования**
   - Убедитесь, что нажата кнопка "Edit"
   - Форма должна быть в режиме редактирования

---

## 🆘 Если не получается

### Проблема: Не вижу список полей справа

**Решение:**
- Убедитесь, что макет открыт для редактирования
- Попробуйте прокрутить страницу вправо
- Обновите страницу (F5)

### Проблема: Не могу перетащить поля

**Решение:**
- Убедитесь, что используете левую кнопку мыши
- Попробуйте кликнуть на поле дважды (может открыть диалог добавления)
- Проверьте, что форма в режиме редактирования

### Проблема: Поля не сохраняются

**Решение:**
- Убедитесь, что нажали "Save"
- Проверьте права доступа (нужны права администратора)
- Попробуйте сохранить еще раз
