# 📦 Как создать новый репозиторий в GitHub

## 🎯 Шаг 1: Создание репозитория на GitHub

### Вариант А: Через веб-интерфейс GitHub

1. **Откройте GitHub:**
   - Перейдите: https://github.com
   - Войдите в свой аккаунт

2. **Создайте новый репозиторий:**
   - Нажмите на иконку **"+"** в правом верхнем углу
   - Выберите **"New repository"**

3. **Заполните форму:**
   - **Repository name:** `tikal-zoho-integration` (или другое название)
   - **Description:** `Интеграция Tikal Call Center с Zoho CRM`
   - **Visibility:** 
     - ✅ **Public** (бесплатно, видно всем)
     - ⚠️ **Private** (платно, только вам)
   - **НЕ ставьте галочки:**
     - ❌ Add a README file (создадим сами)
     - ❌ Add .gitignore (уже есть)
     - ❌ Choose a license (опционально)

4. **Нажмите "Create repository"**

---

## 🎯 Шаг 2: Загрузка кода в репозиторий

### Вариант А: Через командную строку (Git)

1. **Откройте PowerShell в папке проекта:**
   ```powershell
   cd "C:\NaymarkCRM\Интеграция_с_Тикаль"
   ```

2. **Инициализируйте Git (если еще не сделано):**
   ```powershell
   git init
   ```

3. **Добавьте файлы:**
   ```powershell
   git add .
   ```

4. **Создайте первый коммит:**
   ```powershell
   git commit -m "Initial commit: Tikal-Zoho integration"
   ```

5. **Подключите удаленный репозиторий:**
   ```powershell
   git remote add origin https://github.com/costarado/tikal-zoho-integration.git
   ```
   ⚠️ Замените `costarado` на ваш GitHub username и `tikal-zoho-integration` на название репозитория

6. **Загрузите код:**
   ```powershell
   git branch -M main
   git push -u origin main
   ```

7. **Введите логин и пароль GitHub** (или используйте Personal Access Token)

---

### Вариант Б: Через GitHub Desktop (проще)

1. **Скачайте GitHub Desktop:**
   - https://desktop.github.com

2. **Установите и войдите** в свой GitHub аккаунт

3. **Создайте репозиторий:**
   - File → New Repository
   - Name: `tikal-zoho-integration`
   - Local Path: `C:\NaymarkCRM\Интеграция_с_Тикаль`
   - ✅ Initialize this repository with a README (опционально)
   - Create Repository

4. **Загрузите код:**
   - Нажмите "Publish repository"
   - Выберите "Keep this code private" (если нужно)
   - Publish

---

## 🎯 Шаг 3: Подключение к Railway

После создания репозитория на GitHub:

1. **Вернитесь на Railway:**
   - https://railway.app/new/github

2. **Обновите страницу** (F5) или нажмите "Configure GitHub App"

3. **Выберите ваш новый репозиторий:**
   - `costarado/tikal-zoho-integration` (или как вы назвали)

4. **Railway автоматически начнет развертывание**

## 📋 Что загружать в репозиторий

### ✅ Загрузите:
- `zoho_call_service_production.py`
- `tikal_client/` (вся папка)
- `requirements.txt`
- `Procfile`
- `runtime.txt`
- `.gitignore`
- Все `.py` файлы проекта
- Документацию (`.md` файлы)

### ❌ НЕ загружайте:
- `config.py` (содержит секреты!)
- `*.bat` файлы (не нужны на сервере)
- `__pycache__/` (автоматически игнорируется)
- `.env` файлы (если есть)

## 🔐 Безопасность: Personal Access Token

Если Git запрашивает пароль, используйте **Personal Access Token**:

1. **Создайте токен:**
   - GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
   - Generate new token (classic)
   - Выберите scope: `repo` (полный доступ к репозиториям)
   - Generate token
   - **Скопируйте токен** (показывается только один раз!)

2. **Используйте токен вместо пароля:**
   - При `git push` введите:
     - Username: ваш GitHub username
     - Password: вставьте токен (не пароль!)

## 🆘 Проблемы?

### Ошибка: "Repository not found"
- Проверьте название репозитория
- Убедитесь, что вы авторизованы в GitHub
- Проверьте права доступа

### Ошибка: "Authentication failed"
- Используйте Personal Access Token вместо пароля
- Проверьте, что токен имеет права `repo`

### Репозиторий не виден в Railway
- Обновите страницу (F5)
- Нажмите "Configure GitHub App"
- Разрешите доступ Railway к репозиториям
