# Проверка: служебные карточки и оформление Доната (операторы)

**Дата проверки:** 28 октября 2026, ~14:15 (Asia/Jerusalem)  
**Источник:** Zoho CRM API (профиль `Operator`, id `6878864000004151901`)  
**Жалоба:** операторы не могут оформить Донат через служебную карточку

## Вердикт

Открывать карточку контакта операторы **могут** (View + View All Contacts).  
Создавать/править **Пожертвования** по профилю **тоже могут**.  

Главный подозреваемый блокер полного оформления доната: модуль **Payments** у Operator **полностью выключен** (нет View / Create / Edit). Если после/вместе с Донатом создаётся оплата (PayPlus → Payments), оператор упрётся в отказ прав.

## Что проверить / исправить в Zoho (админ)

1. **Profiles → Operator → Payments**  
   Включить как минимум **View + Create** (и Edit, если оператор дописывает оплату).
2. **Profiles → Operator → Пожертвования**  
   По желанию включить **View All**, чтобы в related list на контакте были видны все донаты клиента.
3. **Contacts → Layouts → Standard → Related Lists**  
   Убедиться, что список **Пожертвования** включён и для Operator доступно действие New/Create.
4. **Donations → Layouts**  
   Обязательные поля и subform «Donations Types and Summs» видимы/доступны профилю Operator.
5. **Validation Rules / Blueprint / кнопка «Создать донат»**  
   Нет правила, которое требует поле/роль, недоступные оператору.
