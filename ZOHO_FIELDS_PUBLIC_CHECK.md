## 🔍 Проверка: Почему поля не видны в контактах?

### Возможные причины:

1. **Поля есть только в макете создания, но не в макете просмотра**
2. **Данные не были импортированы в поля** (не были сопоставлены при импорте)
3. **Поля скрыты в определенных секциях**

---

## ✅ Шаг 1: Проверка макетов (Layouts)

### Проверьте макет просмотра контакта:

1. **Settings** → **Customization** → **Modules** → **Contacts** → **Layouts**
2. Найдите макет **"Standard"** или **"Detail View"** (Макет просмотра)
3. Нажмите **"Edit"**
4. Проверьте, есть ли кастомные поля в этом макете:
   - Agent ID
   - Extension
   - Tikal Status
   - Queues
   - Queue_Count
   - Active

### Если полей нет в макете просмотра:

1. **Перетащите поля** из списка справа в нужную секцию
2. Или создайте новую секцию: **"Agent Information"** или **"Tikal Information"**
3. **Сохраните** изменения

---

## ✅ Шаг 2: Проверка импортированных данных

### Проверьте, попали ли данные в поля:

1. **Откройте любой контакт агента** (например, "Agent Agent 6701")
2. **Нажмите "Edit"** (Редактировать)
3. **Проверьте, заполнены ли кастомные поля:**
   - Agent ID = должно быть "6701"
   - Extension = должно быть заполнено (если есть данные)
   - Tikal Status = должно быть заполнено (если есть данные)
   - Queues = должно быть "1155" (или список очередей)
   - Queue_Count = должно быть "1" (или число)
   - Active = должно быть отмечено (если "Yes")

### Если поля пустые:

**Проблема:** Данные не были сопоставлены при импорте.

**Решение:** Переимпортируйте с правильным сопоставлением (см. ниже)

---

## ✅ Шаг 3: Включение поиска по полям

### Для каждого кастомного поля:

1. **Settings** → **Customization** → **Modules** → **Contacts** → **Fields**
2. Найдите поле (например, **"Agent ID"**)
3. **Нажмите на поле** для редактирования
4. Найдите опцию **"Searchable"** (Доступно для поиска)
5. **Включите** эту опцию (отметьте галочкой)
6. **Сохраните** изменения

### Повторите для всех полей:

- ✅ Agent ID → Searchable = ON
- ✅ Extension → Searchable = ON
- ✅ Queues → Searchable = ON
- ✅ Tikal Status → Searchable = ON (опционально)
