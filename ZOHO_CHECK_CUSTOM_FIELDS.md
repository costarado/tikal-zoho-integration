# 🔍 Проверка кастомных полей и настройка поиска в Zoho CRM

## ⚠️ Проблема: Кастомные поля не видны / Поиск не работает

Если после импорта:
- ✅ Контакты созданы
- ❌ Кастомные поля (Agent ID, Extension, Status, Queues) не видны
- ❌ Поиск по Agent ID не работает

---

## 🔍 Шаг 1: Проверка кастомных полей в контакте

### Где искать кастомные поля:

1. **Откройте любой контакт агента** (например, "Agent Agent 6701")
2. **Прокрутите вниз** в разделе "Contact Information"
3. **Ищите секции:**
   - "Custom Information" (Кастомная информация)
   - "Additional Information" (Дополнительная информация)
   - Или просто прокрутите до конца формы

4. **Кастомные поля должны быть там:**
   - Agent ID
   - Extension
   - Tikal Status (или Status)
   - Queues
   - Queue Count
   - Active (Is Active)

### Если поля не видны:

**Возможные причины:**
1. ❌ Поля не были сопоставлены при импорте
2. ❌ Поля скрыты в настройках формы
3. ❌ Данные не попали в поля

**Решение:** См. Шаг 2

---

## 🔧 Шаг 2: Проверка сопоставления полей при импорте

### Если поля не были сопоставлены:

1. **Проверьте историю импорта:**
   - Settings → Data Administration → Import History
   - Найдите последний импорт
   - Посмотрите, какие поля были сопоставлены

2. **Если поля не сопоставлены - переимпортируйте:**
   - Импортируйте файл заново
   - **ВНИМАНИЕ:** При сопоставлении полей обязательно сопоставьте:
     - `Agent ID` → `Agent ID` (ваше кастомное поле)
     - `Extension` → `Extension` (ваше кастомное поле)
     - `Status` → `Tikal Status` (ваше кастомное поле)
     - `Queues` → `Queues` (ваше кастомное поле)
     - `Queue Count` → `Queue_Count1` (ваше кастомное поле)
     - `Is Active` → `Active` (ваше кастомное поле)

3. **Выберите опцию:** "Update existing records" (Обновить существующие записи)

---

## 🔍 Шаг 3: Настройка видимости полей

Если поля созданы, но не видны в форме:

1. **Settings** → **Customization** → **Modules** → **Contacts**
2. Перейдите на вкладку **"Layouts"** (Макеты)
3. Выберите нужный макет (обычно "Standard")
4. Нажмите **"Edit"** (Редактировать)
5. Найдите кастомные поля в списке справа
6. **Перетащите поля** в нужную секцию формы (например, "Contact Information")
7. **Сохраните** изменения

---

## 🔎 Шаг 4: Настройка поиска по кастомным полям

### Проблема: Поиск не находит по Agent ID

**Причина:** По умолчанию Zoho не индексирует кастомные поля для поиска.

### Решение 1: Включить поиск по полю

1. **Settings** → **Customization** → **Modules** → **Contacts** → **Fields**
2. Найдите поле **"Agent ID"**
3. Нажмите на него для редактирования
4. Найдите опцию **"Searchable"** (Доступно для поиска)
5. **Включите** эту опцию (отметьте галочкой)
6. **Сохраните** изменения

**Повторите для других полей:**
- Extension
- Queues
- Status

### Решение 2: Использовать расширенный поиск

1. В модуле **Contacts** нажмите на иконку поиска
2. Выберите **"Advanced Search"** (Расширенный поиск)
3. Добавьте условие:
   - **Field:** Agent ID
   - **Operator:** equals (равно) или contains (содержит)
   - **Value:** (введите Agent ID, например, `6701`)
4. Нажмите **"Search"**

### Решение 3: Использовать фильтр

1. В разделе **"Filter Contacts by"** → **"Filter By Fields"**
2. Найдите поле **"Agent ID"**
3. Введите значение (например, `6701`)
4. Нажмите **"Apply Filter"**

## 📊 Шаг 5: Почему число контактов не изменилось?

### Возможные причины:

1. **Дубликаты были пропущены:**
   - Если при импорте выбрана опция "Skip duplicates"
   - Zoho пропустил контакты, которые уже существовали
   - Новые контакты не создались, существующие не обновились

2. **Контакты были обновлены, а не созданы:**
   - Если выбрана опция "Update existing records"
   - Zoho обновил существующие контакты вместо создания новых
   - Общее число контактов не изменилось

3. **Контакты уже существовали:**
   - Если ранее уже были импортированы агенты
   - Zoho сопоставил по какому-то полю (например, Last Name или Email)
   - И обновил существующие записи

### Как проверить:

1. **Проверьте историю импорта:**
   - Settings → Data Administration → Import History
   - Найдите последний импорт
   - Посмотрите:
     - Сколько записей обработано
     - Сколько создано новых
     - Сколько обновлено
     - Сколько пропущено (дубликаты)

2. **Проверьте фильтром:**
   - Примените фильтр: **Department = "Call Center"**
   - Посмотрите количество записей
   - Сравните с количеством до импорта

## 🔄 Шаг 6: Переимпорт с правильным сопоставлением

Если кастомные поля не заполнились:

1. **Удалите импортированные контакты** (опционально, если нужно начать заново):
   - Примените фильтр: **Department = "Call Center"** + **Lead Source = "Tikal Call Center"**
   - Выберите все контакты
   - Действия → Удалить

2. **Импортируйте файл заново:**
   - Contacts → Import
   - Загрузите: `zoho_import_FIXED_20260108_131553.csv`

3. **При сопоставлении полей:**
   - **ОБЯЗАТЕЛЬНО** сопоставьте кастомные поля вручную:
     - `Agent ID` → выберите `Agent ID` из списка
     - `Extension` → выберите `Extension` из списка
     - `Status` → выберите `Tikal Status` из списка
     - `Queues` → выберите `Queues` из списка
     - `Queue Count` → выберите `Queue_Count1` из списка
     - `Is Active` → выберите `Active` из списка

4. **Выберите опцию:**
   - **"Create new records"** (Создать новые записи) - если хотите создать новые
   - **"Update existing records"** (Обновить существующие) - если хотите обновить

5. **Нажмите Import**
