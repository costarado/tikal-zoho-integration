- ✅ Поиск работает (если включен)

### 2. Использование системы

#### Просмотр агентов в Zoho CRM:

1. Откройте **Zoho CRM** → **Contacts**
2. Примените фильтр: **Department = "Call Center"**
3. Вы увидите всех импортированных агентов

#### Поиск конкретного агента:

1. В модуле **Contacts** используйте поиск
2. Введите **Agent ID** (например, `6701`)
3. Найдет контакт агента

#### Просмотр информации об агенте:

1. Откройте контакт агента
2. Увидите все кастомные поля:
   - Agent ID
   - Extension
   - Tikal Status
   - Queues (список очередей)
   - Queue Count
   - Active

### 3. Обновление данных (при необходимости)

Если нужно обновить данные агентов:

```bash
# Получить свежие данные из Tikal
python get_active_agents_only.py

# Подготовить файл для импорта
python prepare_zoho_import.py

# Импортировать в Zoho (через веб-интерфейс)
# Contacts → Import → загрузить новый CSV
```

### 4. Автоматизация (опционально)

#### Настройка периодической синхронизации:

1. Создайте задачу в планировщике Windows
2. Запускайте `get_active_agents_only.py` ежедневно
3. Импортируйте обновленные данные в Zoho

#### Или используйте Zoho Deluge (Zoho Workflow):

- Настройте автоматический импорт через Zoho Workflow
- См. примеры: `zoho_sync_script.py`
