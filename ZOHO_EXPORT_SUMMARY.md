## Структура данных

Каждый агент содержит:
- **Agent ID** - Уникальный ID в Tikal
- **Queues** - Список очередей, в которых работает агент
- **Extension** - Внутренний номер (если доступен)
- **Status** - Статус агента (если доступен)
- **Name** - Имя агента (если доступно)

## Импорт в Zoho CRM

### Шаг 1: Подготовка

Файл `zoho_agents_import_20260105_133136.csv` готов к импорту.

### Шаг 2: Импорт

1. Войдите в **Zoho CRM**
2. Перейдите в **Contacts** → **Import**
3. Загрузите файл `zoho_agents_import_20260105_133136.csv`
4. Zoho автоматически определит поля
5. Проверьте сопоставление:
   - First Name → First Name
   - Last Name → Last Name
   - Phone → Phone
   - Agent ID → Custom Field (если нужно)
6. Завершите импорт

### Шаг 3: После импорта

- Проверьте количество импортированных контактов (должно быть 146)
- Добавьте email адреса вручную, если нужно
- Добавьте имена агентов, если они отсутствуют
- Создайте группы/теги для организации

## Важные замечания

1. **Имена агентов:** Некоторые агенты могут не иметь имен в системе. Используйте Agent ID для идентификации.

2. **Email адреса:** Поле Email пустое. Добавьте email адреса вручную в Zoho после импорта.

3. **Дубликаты:** Zoho автоматически определит дубликаты при импорте. Проверьте перед завершением.

4. **Кастомные поля:** Agent ID, Extension, Status, Queues можно сохранить в кастомных полях Zoho.

```python
from tikal_client.tikal_client_v2 import TikalClientV2
from config import TIKAL_CONFIG

client = TikalClientV2(...)

export_to_zoho_format(agents, 'zoho_agents_latest.csv')
```
