# 🔄 Автоматическое обновление Access Token

## ✅ Проблема решена!

Создан скрипт `auto_update_token.py`, который:
- ✅ Автоматически обновляет Access Token
- ✅ Автоматически обновляет config.py
- ✅ Не требует интерактивного ввода

---

## 🚀 Использование

### Способ 1: Через батник (РЕКОМЕНДУЕТСЯ)

Дважды кликните на:
```
refresh_token.bat
```

### Способ 2: Через командную строку

```bash
cd "C:\NaymarkCRM\Интеграция_с_Тикаль"
python auto_update_token.py
```

### Способ 3: Через главное меню

Дважды кликните на:
```
START_HERE.bat
```

Выберите пункт **2. Обновление Access Token**

---

## ⏱️ Когда обновлять токен

Access Token действителен **~1 час** (3600 секунд).

Обновляйте токен:
- ✅ При ошибке "INVALID_TOKEN"
- ✅ При ошибке 401 Unauthorized
- ✅ Периодически (если используете API часто)

---

## 🔧 Как это работает

1. Скрипт использует Refresh Token из config.py
2. Отправляет запрос в Zoho для получения нового Access Token
3. Автоматически обновляет config.py с новым токеном
4. Готово! Токен обновлен и сохранен
