# Инструкция по созданию кастомных полей в Zoho CRM

## 📋 Обзор

Для корректного импорта агентов из Tikal Call Center в Zoho CRM необходимо создать **5 кастомных полей** в модуле **Contacts**.

---

## 🎯 Шаг 1: Откройте настройки модуля Contacts

1. Войдите в **Zoho CRM**
2. Нажмите на иконку **⚙️ Settings** (Настройки) в правом верхнем углу
3. В левом меню выберите: **Customization** → **Modules**
4. Найдите модуль **Contacts** (Контакты) в списке
5. Нажмите на **Contacts** для открытия настроек модуля

---

## 🎯 Шаг 2: Создайте кастомные поля

В открывшемся окне настроек модуля Contacts:

1. Перейдите на вкладку **Fields** (Поля)
2. Нажмите кнопку **Add Fields** (Добавить поля) или **+ Add Field**

Теперь создайте каждое поле по инструкции ниже:

---

### 📝 Поле 1: Agent ID

**Назначение:** Уникальный идентификатор агента в системе Tikal

**Настройки:**
- **Field Type (Тип поля):** `Text` (Текст)
- **Field Label (Метка поля):** `Agent ID`
- **Field Name (Имя поля):** `Agent_ID` (автоматически)
- **Length (Длина):** `50`
- **Required (Обязательное):** ❌ **No**
- **Unique (Уникальное):** ✅ **Yes** (рекомендуется для предотвращения дубликатов)
- **Visible (Видимое):** ✅ **Yes**

**Нажмите:** `Save` (Сохранить)

---

### 📝 Поле 2: Extension

**Назначение:** Внутренний номер/расширение агента

**Настройки:**
- **Field Type (Тип поля):** `Text` (Текст)
- **Field Label (Метка поля):** `Extension`
- **Field Name (Имя поля):** `Extension` (автоматически)
- **Length (Длина):** `20`
- **Required (Обязательное):** ❌ **No**
- **Visible (Видимое):** ✅ **Yes**

**Нажмите:** `Save` (Сохранить)

---

### 📝 Поле 3: Status

**Назначение:** Текущий статус агента в системе Tikal

**Настройки:**
- **Field Type (Тип поля):** `Picklist` (Выпадающий список)
- **Field Label (Метка поля):** `Tikal Status` или `Status`
- **Field Name (Имя поля):** `Tikal_Status` или `Status` (автоматически)
- **Required (Обязательное):** ❌ **No**
- **Visible (Видимое):** ✅ **Yes**

**Значения для Picklist (добавьте через кнопку "Add"):**
- `Online`
- `Offline`
- `Ready`
- `Busy`
- `Not Available`
- (оставьте пустое значение для пустых записей)

**Нажмите:** `Save` (Сохранить)

---

### 📝 Поле 4: Queues

**Назначение:** Список очередей, в которых работает агент

**Настройки:**
- **Field Type (Тип поля):** `Text` (Текст) или `Multi-Line Text` (Многострочный текст)
- **Field Label (Метка поля):** `Queues`
- **Field Name (Имя поля):** `Queues` (автоматически)
- **Length (Длина):** `500` (если Text) или без ограничений (если Multi-Line)
- **Required (Обязательное):** ❌ **No**
- **Visible (Видимое):** ✅ **Yes**

> **Примечание:** Это поле будет содержать список ID очередей через запятую (например: "1155, 1135, 1163")

**Нажмите:** `Save` (Сохранить)

---

### 📝 Поле 5: Queue Count

**Назначение:** Количество очередей, в которых работает агент

**Настройки:**
- **Field Type (Тип поля):** `Number` (Число) или `Integer` (Целое число)
- **Field Label (Метка поля):** `Queue Count`
- **Field Name (Имя поля):** `Queue_Count` (автоматически)
- **Decimal Places (Знаков после запятой):** `0` (если Number)
- **Required (Обязательное):** ❌ **No**
- **Visible (Видимое):** ✅ **Yes**

**Нажмите:** `Save` (Сохранить)

---

### 📝 Поле 6: Is Active (Опционально)

**Назначение:** Индикатор активности агента

**Настройки:**
- **Field Type (Тип поля):** `Checkbox` (Чекбокс) или `Picklist` (Выпадающий список)
- **Field Label (Метка поля):** `Is Active`
- **Field Name (Имя поля):** `Is_Active` (автоматически)
- **Required (Обязательное):** ❌ **No**
- **Visible (Видимое):** ✅ **Yes**

**Если Checkbox:**
- **Default Value (Значение по умолчанию):** ✅ **Checked** (отмечен)

**Если Picklist:**
- **Значения:** `Yes`, `No`

**Нажмите:** `Save` (Сохранить)

---

## 🎯 Шаг 3: Проверка созданных полей

После создания всех полей:

1. Вернитесь в модуль **Contacts**
2. Откройте любой контакт или создайте новый
3. Убедитесь, что все созданные поля отображаются в форме
4. Проверьте, что поля имеют правильные типы и метки

---

## 🎯 Шаг 4: Импорт данных

Теперь можно импортировать подготовленный CSV файл:

1. Перейдите в модуль **Contacts** (Контакты)
2. Нажмите кнопку **Import** (Импорт) или **⋮** (три точки) → **Import**
3. Выберите **Upload File** (Загрузить файл)
4. Загрузите подготовленный CSV файл (`zoho_import_READY_*.csv`)
5. Zoho автоматически определит большинство стандартных полей

---

## 🎯 Шаг 5: Сопоставление полей при импорте

После загрузки файла Zoho покажет экран сопоставления полей:

### Стандартные поля (автоматически сопоставятся):
- ✅ `First Name` → `First Name`
- ✅ `Last Name` → `Last Name`
- ✅ `Email` → `Email`
- ✅ `Phone` → `Phone`
- ✅ `Mobile` → `Mobile`
- ✅ `Title` → `Title`
- ✅ `Department` → `Department`
- ✅ `Lead Source` → `Lead Source`
- ✅ `Description` → `Description`

### Кастомные поля (нужно сопоставить вручную):
- 🔹 `Agent ID` → выберите `Agent ID` (ваше созданное поле)
- 🔹 `Extension` → выберите `Extension` (ваше созданное поле)
- 🔹 `Status` → выберите `Tikal Status` или `Status` (ваше созданное поле)
- 🔹 `Queues` → выберите `Queues` (ваше созданное поле)
- 🔹 `Queue Count` → выберите `Queue Count` (ваше созданное поле)
- 🔹 `Is Active` → выберите `Is Active` (ваше созданное поле, если создали)

**Важно:** Если поле не найдено в списке, убедитесь, что:
- Поле создано и сохранено
- Поле видимо в форме контакта
- Имя поля в CSV точно совпадает с меткой поля в Zoho

---

## 🎯 Шаг 6: Завершение импорта

1. Проверьте все сопоставления полей
2. Выберите опцию обработки дубликатов (если нужно):
   - **Skip** (Пропустить) - если контакт уже существует
   - **Update** (Обновить) - обновить существующий контакт
   - **Create** (Создать) - создать новый контакт
3. Нажмите **Import** (Импорт)
4. Дождитесь завершения импорта
5. Проверьте результаты импорта

---

## ✅ Проверка после импорта

После успешного импорта проверьте:

1. ✅ Все агенты импортированы
2. ✅ Поля `Agent ID` заполнены и уникальны
3. ✅ Поля `Extension`, `Status`, `Queues` заполнены корректно
4. ✅ Нет дубликатов (если установлена уникальность `Agent ID`)
5. ✅ Описание (`Description`) содержит всю информацию

## 🆘 Решение проблем

### Проблема: Поле не отображается при сопоставлении

**Решение:**
- Убедитесь, что поле создано и сохранено
- Проверьте, что поле видимо в форме контакта
- Обновите страницу импорта
- Проверьте точное совпадение имени поля

### Проблема: Ошибка при импорте числовых полей

**Решение:**
- Убедитесь, что поле `Queue Count` имеет тип `Number` или `Integer`
- Проверьте, что в CSV файле нет нечисловых значений в этом поле

### Проблема: Многострочный текст в Description

**Решение:**
- Файл уже подготовлен скриптом `prepare_zoho_import.py`
- Переносы строк заменены на ` | ` для корректного отображения

### Проблема: Дубликаты контактов

**Решение:**
- Установите поле `Agent ID` как **Unique** (Уникальное)
- При импорте выберите опцию **Skip** для дубликатов
- Или используйте `Agent ID` для обновления существующих контактов

---

## 📞 Дополнительная помощь

Если возникли проблемы:
1. Проверьте логи импорта в Zoho CRM
2. Убедитесь, что все поля созданы правильно
3. Проверьте формат CSV файла (кодировка UTF-8-BOM)
