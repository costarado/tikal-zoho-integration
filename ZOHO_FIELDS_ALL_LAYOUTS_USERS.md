# 🔧 Настройка полей для всех макетов и всех пользователей в Zoho CRM

## 🎯 Цель

Сделать кастомные поля (Agent ID, Extension, Tikal Status, Queues и т.д.) видимыми:
- ✅ Во всех макетах (Create, Edit, Detail View)
- ✅ Для всех пользователей
- ✅ Во всех секциях и представлениях

---

## 📋 Шаг 1: Добавление полей во все макеты

### 1.1. Откройте настройки макетов

1. **Settings** → **Customization** → **Modules** → **Contacts**
2. Перейдите на вкладку **"Layouts"** (Макеты)
3. Вы увидите список макетов:
   - Standard (Стандартный)
   - Create Contact (Создание контакта)
   - Detail View (Просмотр контакта)
   - И другие (если есть)

### 1.2. Добавьте поля в каждый макет

Для каждого макета:

1. **Нажмите на макет** (например, "Standard")
2. Нажмите **"Edit"** (Редактировать)
3. **Найдите кастомные поля** в списке справа (в разделе "Unused Fields" или внизу)
4. **Перетащите поля** в нужную секцию формы:
   - Agent ID
   - Extension
   - Tikal Status
   - Queues
   - Queue_Count
   - Active

5. **Сохраните** изменения (Save или Save and Close)

### 1.3. Создайте секцию для полей агентов (рекомендуется)

Для лучшей организации:

1. В макете нажмите **"NEW SECTION"** (Новая секция)
2. Назовите секцию: **"Agent Information"** или **"Tikal Information"**
3. **Перетащите все кастомные поля** в эту секцию:
   - Agent ID
   - Extension
   - Tikal Status
   - Queues
   - Queue_Count
   - Active
4. **Сохраните** изменения

### 1.4. Повторите для всех макетов

**Обязательно добавьте поля в:**
- ✅ **Standard** (Стандартный) - основной макет
- ✅ **Create Contact** (Создание контакта) - форма создания
- ✅ **Detail View** (Просмотр контакта) - форма просмотра
- ✅ **Edit Contact** (Редактирование контакта) - форма редактирования
- ✅ Любые другие кастомные макеты

---

## 👥 Шаг 2: Настройка видимости для всех пользователей

### 2.1. Проверьте настройки полей

1. **Settings** → **Customization** → **Modules** → **Contacts** → **Fields**
2. Найдите каждое кастомное поле:
   - Agent ID
   - Extension
   - Tikal Status
   - Queues
   - Queue_Count
   - Active

### 2.2. Настройте видимость полей

Для каждого поля:

1. **Нажмите на поле** (например, "Agent ID")
2. Найдите раздел **"Field Properties"** или **"Properties"**
3. Проверьте настройки:

   **Visibility (Видимость):**
   - ✅ **"Visible to All"** или **"Public"** - должно быть включено
   - ❌ Не должно быть "Visible to Owner Only" или "Hidden"

   **Required (Обязательное):**
   - ❌ Оставьте **"No"** (необязательное)

   **Read Only (Только для чтения):**
   - ❌ Оставьте **"No"** (если нужно редактировать)

4. **Сохраните** изменения

### 2.3. Настройка прав доступа (Permissions)

1. В настройках поля найдите раздел **"Permissions"** или **"Field Level Security"**
2. Убедитесь, что:
   - ✅ **"Visible"** (Видимо) - для всех ролей
   - ✅ **"Editable"** (Редактируемо) - для нужных ролей (или для всех)
   - ❌ Не должно быть ограничений по ролям

3. Если есть ограничения:
   - Нажмите **"Edit Permissions"**
   - Для каждой роли установите:
     - ✅ Visible = Yes
     - ✅ Editable = Yes (если нужно)
   - **Сохраните** изменения

---

## 🔐 Шаг 3: Настройка профилей и ролей

### 3.1. Проверьте профили пользователей

1. **Settings** → **Users & Permissions** → **Profiles**
2. Для каждого профиля проверьте:
   - ✅ Модуль "Contacts" доступен
   - ✅ Права на просмотр и редактирование контактов

### 3.2. Проверьте роли

1. **Settings** → **Users & Permissions** → **Roles**
2. Для каждой роли проверьте:
   - ✅ Доступ к модулю "Contacts"
   - ✅ Права на просмотр и редактирование

---

## 📊 Шаг 4: Настройка представлений (Views)

### 4.1. Добавьте поля в представления списка

1. В модуле **Contacts** найдите иконку **"Columns"** или **"⚙️"** (Настройки колонок)
2. Нажмите на нее
3. **Добавьте кастомные поля** в список отображаемых колонок:
   - ✅ Agent ID
   - ✅ Extension
   - ✅ Tikal Status
   - ✅ Queues
   - ✅ Queue_Count
   - ✅ Active
4. **Сохраните** представление

### 4.2. Создайте сохраненное представление

1. Настройте нужные колонки (включая кастомные поля)
2. Примените нужные фильтры (если нужно)
3. Нажмите **"Save View"** или **"Save as View"**
4. Назовите представление: **"Tikal Agents"** или **"Call Center Agents"**
5. Теперь это представление будет доступно всем пользователям

---

## 🔍 Шаг 5: Включение поиска для всех

### 5.1. Включите поиск для каждого поля

1. **Settings** → **Customization** → **Modules** → **Contacts** → **Fields**
2. Для каждого кастомного поля:
   - **Agent ID** → включите **"Searchable"**
   - **Extension** → включите **"Searchable"**
   - **Queues** → включите **"Searchable"**
   - **Tikal Status** → включите **"Searchable"** (опционально)
3. **Сохраните** изменения

### 5.2. Проверьте глобальный поиск

1. В верхней части Zoho CRM найдите строку **глобального поиска**
2. Введите Agent ID (например, `6701`)
3. Должен найти контакт (если поиск включен)

---

## ✅ Шаг 6: Проверка для всех пользователей

### 6.1. Проверьте от имени другого пользователя

1. **Выйдите** из текущего аккаунта
2. **Войдите** под другим пользователем (или попросите коллегу проверить)
3. Проверьте:
   - ✅ Поля видны в форме создания контакта
   - ✅ Поля видны в форме просмотра контакта
   - ✅ Поля видны в форме редактирования
   - ✅ Поля видны в списке контактов (если добавлены в колонки)
   - ✅ Поиск работает по кастомным полям

### 6.2. Если поля не видны для других пользователей

**Проверьте:**
1. Настройки полей (Visibility = Public)
2. Права доступа (Permissions) для ролей
3. Настройки макетов (поля добавлены во все макеты)
4. Профили пользователей (доступ к модулю Contacts)

## 🎯 Быстрая инструкция

### Для всех макетов:

1. **Settings** → **Customization** → **Modules** → **Contacts** → **Layouts**
2. Для каждого макета:
   - Нажмите **"Edit"**
   - Перетащите кастомные поля в форму
   - **Сохраните**

### Для всех пользователей:

1. **Settings** → **Customization** → **Modules** → **Contacts** → **Fields**
2. Для каждого поля:
   - Убедитесь, что **"Public"** или **"Visible to All"**
   - Проверьте **Permissions** - все роли должны иметь доступ
   - Включите **"Searchable"**

### Для представлений:

1. В модуле **Contacts** → **Columns** (Колонки)
2. Добавьте кастомные поля в список
3. **Сохраните** представление

## 🆘 Решение проблем

### Проблема: Поля не видны для некоторых пользователей

**Решение:**
1. Проверьте настройки полей (Visibility = Public)
2. Проверьте права доступа (Permissions) для ролей пользователей
3. Проверьте профили пользователей (доступ к модулю Contacts)

### Проблема: Поля не видны в определенном макете

**Решение:**
1. Откройте настройки макета
2. Убедитесь, что поля добавлены в этот макет
3. Сохраните изменения

### Проблема: Поиск не работает для других пользователей

**Решение:**
1. Убедитесь, что поиск включен (Searchable = ON)
2. Проверьте права доступа на просмотр контактов
3. Проверьте, что пользователь имеет доступ к модулю Contacts

---

**Готово!** Теперь кастомные поля будут видны во всех макетах и для всех пользователей. 🎉
