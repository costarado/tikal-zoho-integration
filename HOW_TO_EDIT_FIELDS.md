# 🔧 Как открыть настройки поля в Zoho CRM

## ⚠️ Проблема: Поля не кликабельны в списке

Если на странице "Field Listing" поля не кликабельны, используйте альтернативные способы:

---

## 🎯 Способ 1: Через меню действий (⋮)

1. Найдите нужное поле в списке (например, "Extension")
2. Наведите курсор на строку с полем
3. Справа от строки должна появиться иконка **"⋮"** (три точки) или **"..."**
4. **Кликните на иконку** - откроется меню
5. Выберите **"Edit"** (Редактировать) или **"Edit Field"**

---

## 🎯 Способ 2: Через кнопку "Edit" вверху

1. На странице "Field Listing" найдите поле
2. **Отметьте галочкой** поле (чекбокс слева от названия)
3. Вверху страницы должна появиться кнопка **"Edit"** или **"Actions"**
4. **Кликните на кнопку** → выберите **"Edit"**

---

## 🎯 Способ 3: Прямой переход к полю

1. В левом меню: **Settings** → **Customization** → **Modules** → **Contacts**
2. Перейдите на вкладку **"Fields"** (если не открыта)
3. Найдите поле в списке
4. Попробуйте **двойной клик** на названии поля
5. Или используйте **правый клик** → **Edit**

---

## 🎯 Способ 4: Через поиск поля

1. Вверху страницы "Field Listing" есть **поиск**
2. Введите название поля (например, "Extension")
3. Нажмите Enter
4. После того как поле найдено, попробуйте способы выше

---

## 🎯 Способ 5: Через URL напрямую

Если знаете API имя поля, можно открыть напрямую:

1. URL должен быть примерно таким:
   ```
   https://crm.zoho.com/crm/org893969151/settings/modules/Contacts/fields/{field_id}
   ```

2. Или через настройки модуля:
   - **Settings** → **Customization** → **Modules** → **Contacts** → **Fields**
   - Найдите поле и попробуйте открыть

---

## 🔍 Альтернатива: Настройка через Layout Editor

Если поля не редактируются через Field Listing:

1. **Settings** → **Customization** → **Modules** → **Contacts** → **Layouts**
2. Выберите макет (например, "Standard")
3. Нажмите **"Edit"**
4. Найдите поле в списке справа
5. **Правый клик** на поле → **"Edit Field"** или **"Field Properties"**

---

## 💡 Быстрый способ для включения поиска

Если нужно только включить поиск:

1. **Settings** → **Customization** → **Modules** → **Contacts** → **Fields**
2. Найдите поле (например, "Extension")
3. Используйте **правый клик** на поле
4. Выберите **"Field Properties"** или **"Edit"**
5. В открывшемся окне найдите **"Searchable"**
6. Включите галочку ✅
7. **Save**

---

## 🆘 Если ничего не помогает

### Вариант 1: Проверьте права доступа
- Убедитесь, что у вас есть права администратора
- Или права на изменение полей

### Вариант 2: Обновите страницу
- Нажмите **F5** или **Ctrl+R**
- Попробуйте снова

### Вариант 3: Используйте другой браузер
- Попробуйте Chrome, Firefox или Edge
- Очистите кеш браузера

### Вариант 4: Проверьте версию Zoho CRM
- Возможно, используется новая версия интерфейса
- Попробуйте переключиться на старый интерфейс (если доступно)

---

## 📝 Пошаговая инструкция для каждого поля

### Для поля "Extension":

1. **Settings** → **Customization** → **Modules** → **Contacts** → **Fields**
2. Найдите **"Extension"** в списке
3. **Правый клик** на "Extension" → **"Edit"**
4. Или наведите курсор → появится **"⋮"** → **"Edit"**
5. В открывшемся окне:
   - Найдите **"Searchable"**
   - Включите ✅
   - **Save**

Повторите для всех 6 полей:
- Extension
- Agent ID
- Tikal Status
- Queues
- Queue Count
- Active

---

## ✅ Проверка

После настройки проверьте:

1. Перейдите в модуль **Contacts**
2. Попробуйте найти контакт по **Extension** или **Agent ID**
3. Если поиск работает - настройка успешна!

---

**Главное:** Используйте правый клик или иконку "⋮" для доступа к настройкам поля! 🎯
