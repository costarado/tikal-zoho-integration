# 🔍 Как найти и просмотреть импортированных агентов в Zoho CRM

## 📍 Где находятся импортированные агенты

После импорта все агенты находятся в модуле **Contacts** (Контакты).

---

## 🎯 Способ 1: Просмотр всех контактов

1. В левом меню выберите **Contacts** (Контакты)
2. Вы увидите список всех контактов, включая импортированных агентов
3. В заголовке будет указано общее количество: **"Total Records: XXX"**

**Как распознать агентов:**
- **First Name:** "Agent"
- **Last Name:** числовой ID (например, "6701", "6702")
- **Title:** "Call Center Agent"
- **Department:** "Call Center"
- **Lead Source:** "Tikal Call Center"

---

## 🔎 Способ 2: Поиск по Agent ID

### Вариант A: Поиск в строке поиска

1. В модуле **Contacts** найдите строку поиска (обычно вверху)
2. Введите **Agent ID** (например, `6701`)
3. Нажмите Enter или кнопку поиска
4. Zoho найдет контакт с таким Agent ID в кастомном поле

### Вариант B: Поиск по Last Name

1. В строке поиска введите числовой ID агента (например, `6701`)
2. Zoho найдет контакт, где Last Name = "6701"

---

## 🎛️ Способ 3: Фильтрация по полям

### Фильтр по Department

1. В модуле **Contacts** найдите раздел **"Filter Contacts by"** (слева)
2. Раскройте **"Filter By Fields"**
3. Найдите поле **"Department"**
4. Выберите значение **"Call Center"**
5. Нажмите **"Apply Filter"**

**Результат:** Вы увидите только агентов (все с Department = "Call Center")

### Фильтр по Title

1. В разделе **"Filter By Fields"**
2. Найдите поле **"Title"**
3. Выберите значение **"Call Center Agent"**
4. Нажмите **"Apply Filter"**

**Результат:** Только агенты колл-центра

### Фильтр по Lead Source

1. В разделе **"Filter By Fields"**
2. Найдите поле **"Lead Source"**
3. Выберите значение **"Tikal Call Center"**
4. Нажмите **"Apply Filter"**

**Результат:** Только агенты, импортированные из Tikal

### Фильтр по кастомному полю Agent ID

1. В разделе **"Filter By Fields"**
2. Найдите поле **"Agent ID"** (ваше кастомное поле)
3. Введите или выберите значение (например, `6701`)
4. Нажмите **"Apply Filter"**

**Результат:** Конкретный агент по его ID

---

## 📊 Способ 4: Настройка отображения колонок

Чтобы видеть Agent ID и другие кастомные поля в списке:

1. В списке контактов найдите иконку **"⚙️"** или **"Columns"** (Колонки)
2. Нажмите на нее
3. Выберите кастомные поля для отображения:
   - ✅ **Agent ID**
   - ✅ **Extension**
   - ✅ **Tikal Status**
   - ✅ **Queues**
   - ✅ **Queue Count**
   - ✅ **Active** (Is Active)
4. Сохраните настройки

**Результат:** В списке контактов будут видны все важные поля агентов

---

## 🔍 Способ 5: Расширенный поиск

1. В модуле **Contacts** нажмите на иконку поиска или **"Advanced Search"**
2. Выберите критерии поиска:
   - **Field:** Agent ID
   - **Operator:** equals / contains
   - **Value:** (введите ID или часть ID)
3. Добавьте дополнительные условия (если нужно):
   - **AND** Department = "Call Center"
   - **AND** Title = "Call Center Agent"
4. Нажмите **"Search"**

---

## 📋 Способ 6: Просмотр отдельного агента

1. Найдите агента в списке (любым из способов выше)
2. Кликните на **Last Name** или **First Name** агента
3. Откроется карточка контакта со всей информацией:
   - Стандартные поля (имя, телефон, должность)
   - Кастомные поля (Agent ID, Extension, Status, Queues и т.д.)
   - Description с полной информацией

---

## ⚠️ Решение проблемы: "Please enter a valid Last Name"

Если при импорте появляется ошибка **"Please enter a valid Last Name"**:

### Причина:
В CSV файле поле **Last Name** содержит только числовые значения (6701, 6702 и т.д.), а Zoho может требовать текстовое значение.

### Решение 1: Исправить CSV перед импортом

1. Откройте файл `zoho_import_READY_20260108_121037.csv` в Excel
2. В колонке **Last Name** измените формат:
   - Было: `6701`
   - Стало: `Agent 6701` или `ID-6701`
3. Сохраните файл
4. Повторите импорт

### Решение 2: Использовать скрипт для исправления

Запустите скрипт для автоматического исправления:

```python
python fix_last_name_for_zoho.py
```

### Решение 3: Импортировать с пропуском ошибок

1. При импорте выберите опцию **"Skip invalid records"**
2. Zoho пропустит записи с невалидным Last Name
3. После импорта вручную исправьте пропущенные записи

## 📈 Быстрая проверка импорта

### Проверка количества импортированных агентов:

1. Перейдите в **Contacts**
2. Примените фильтр: **Department = "Call Center"**
3. Посмотрите количество записей вверху: **"Total Records: XXX"**
4. Сравните с количеством в CSV файле (должно быть 146 активных агентов)

### Проверка данных:

1. Откройте несколько случайных агентов
2. Проверьте, что заполнены:
   - ✅ Agent ID (кастомное поле)
   - ✅ Extension (кастомное поле)
   - ✅ Status (кастомное поле)
   - ✅ Queues (кастомное поле)
   - ✅ Description (с полной информацией)

## 🎯 Рекомендуемый способ для быстрого доступа

**Создайте сохраненный фильтр:**

1. Примените фильтр: **Department = "Call Center"** + **Lead Source = "Tikal Call Center"**
2. Нажмите **"Save Filter"** или **"Save as View"**
3. Назовите фильтр: **"Tikal Agents"** или **"Call Center Agents"**
4. Теперь вы можете быстро переключаться на этот фильтр из выпадающего списка

**Результат:** Один клик - и вы видите всех импортированных агентов!
