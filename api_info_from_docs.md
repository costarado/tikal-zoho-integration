# Информация об API из документации

## Найденная информация

### API Package

API package позволяет выполнять задачи call center программно через API запросы:

- Создание агента (creating an agent)
- Редактирование агента (editing an agent)
- Удаление очереди (deleting a queue)
- Создание звонка между агентом и номером телефона (originating a call)
- И другие задачи

### SEND CDR Service

Сервис для получения уведомлений о каждом входящем или исходящем звонке.

**Настройка:**
- Требуется URL скрипта для обработки данных
- URL указывается при установке API

**Форматы данных:**
- XML
- JSON
- Key-value pairs

**Методы передачи:**
- POST
- GET

**Структура данных:**

Данные передаются в поле `data` как строка (XML или JSON). После парсинга доступны поля:

- `agent_id` - Номер агента
- `queue_id` - Номер очереди
- `caller_id` - Номер телефона звонящего
- `answer_time` - Время ответа на звонок
- `end_time` - Время окончания звонка
- `waiting_time` - Время ожидания
- `duration` - Длительность звонка
- `direction` - Направление (incoming или outgoing)
- `recording_link` - Ссылка на запись звонка
- `call_status` - Статус звонка (answered, unanswered или asterisk status)
- `custom1`, `custom2` - Пользовательские поля (передаются через originate API)
