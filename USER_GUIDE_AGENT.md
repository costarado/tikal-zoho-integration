# 👤 Руководство для Агента: Работа с Zoho CRM

## 📋 Что может делать агент

Как агент колл-центра, вы можете использовать Zoho CRM для:
- ✅ Просмотра информации о других агентах
- ✅ Поиска агентов по ID или имени
- ✅ Просмотра статусов агентов
- ✅ Просмотра очередей, в которых работают агенты

---

## 🔍 Как найти агента

### Способ 1: Поиск по Agent ID

1. Откройте **Zoho CRM** → **Contacts** (Контакты)
2. В строке поиска введите **Agent ID** (например, `6701`)
3. Нажмите Enter
4. Откроется контакт агента

### Способ 2: Фильтр по Agent ID

1. В модуле **Contacts** найдите раздел **"Filter Contacts by"** (слева)
2. Раскройте **"Filter By Fields"**
3. Найдите поле **"Agent ID"**
4. Введите значение (например, `6701`)
5. Нажмите **"Apply Filter"**

### Способ 3: Фильтр по Department

1. В разделе **"Filter By Fields"**
2. Найдите **"Department"**
3. Выберите **"Call Center"**
4. Нажмите **"Apply Filter"**

**Результат:** Вы увидите всех агентов колл-центра

---

## 📊 Просмотр информации об агенте

После поиска или фильтрации:

1. **Кликните на контакт агента** в списке
2. Откроется карточка контакта с информацией:

### Доступная информация:

- **Agent ID** - уникальный идентификатор агента
- **Extension** - внутренний номер
- **Tikal Status** - текущий статус (Online, Offline, Ready, Busy и т.д.)
- **Queues** - список очередей, в которых работает агент
- **Queue Count** - количество очередей
- **Active** - активен ли агент

### Дополнительная информация:

- **First Name, Last Name** - имя агента
- **Phone** - телефон
- **Department** - отдел (Call Center)
- **Title** - должность (Call Center Agent)
- **Description** - подробная информация об агенте

## 🔎 Примеры использования

### Пример 1: Найти коллегу по Agent ID

**Задача:** Найти агента с ID 6701

**Шаги:**
1. Contacts → поиск → введите `6701`
2. Откройте найденный контакт
3. Посмотрите информацию об агенте

### Пример 2: Посмотреть всех активных агентов

**Задача:** Увидеть всех агентов колл-центра

**Шаги:**
1. Contacts → Filter By Fields → Department = "Call Center"
2. Apply Filter
3. Просмотрите список агентов

### Пример 3: Найти агентов в определенной очереди

**Задача:** Найти агентов, работающих в очереди 1155

**Шаги:**
1. Contacts → Filter By Fields → Queues
2. Введите `1155` или используйте поиск
3. Apply Filter
4. Просмотрите список агентов

## ⚠️ Ограничения для агента

Как агент, вы **НЕ можете**:
- ❌ Редактировать информацию об агентах (только просмотр)
- ❌ Создавать новых агентов
- ❌ Удалять агентов
- ❌ Изменять статусы агентов (это делается в системе Tikal)

Вы можете только **просматривать** информацию.

---

## 💡 Полезные советы

1. **Используйте сохраненные фильтры:**
   - После настройки фильтра нажмите **"Save Filter"**
   - Назовите его "Call Center Agents"
   - Теперь можно быстро переключаться на этот фильтр

2. **Настройте колонки:**
   - В списке контактов нажмите иконку **"Columns"**
   - Добавьте колонки: Agent ID, Extension, Tikal Status
   - Теперь эти поля будут видны в списке

3. **Используйте поиск:**
   - Поиск работает по имени, Agent ID, Extension
   - Можно искать частично (например, `67` найдет всех агентов с ID начинающимся с 67)

## 🆘 Если что-то не работает

### Проблема: Не могу найти агента

**Решение:**
- Проверьте, правильно ли введен Agent ID
- Попробуйте использовать фильтр вместо поиска
- Убедитесь, что фильтр Department = "Call Center" не активен

### Проблема: Не вижу кастомные поля

**Решение:**
- Обратитесь к администратору
- Возможно, нужно настроить права доступа

### Проблема: Поиск не работает

**Решение:**
- Обратитесь к администратору
- Возможно, нужно включить поиск для полей

## 📞 Создание звонков из Zoho

**Да, вы можете создавать звонки напрямую из Zoho CRM!**

После настройки администратором:

1. Откройте контакт в Zoho CRM
2. Нажмите кнопку **"Позвонить"** (настроена администратором)
3. Звонок будет создан через Tikal API
4. Ответьте на звонок в системе Tikal

**Требования:**
- В контакте заполнен Agent ID
- В контакте заполнен Phone
- Вы онлайн в системе Tikal

**Подробнее:** См. `USER_GUIDE_AGENT_CALLS.md`
