## 🔧 Что нужно сделать вручную

### 1. Включить поиск для полей (5 минут)

Для каждого поля:
1. **Settings** → **Customization** → **Modules** → **Contacts** → **Fields**
2. Найдите поле (например, "Agent ID")
3. Нажмите на поле
4. Включите опцию **"Searchable"**
5. **Save**

Повторите для:
- Agent ID
- Extension
- Tikal Status
- Queues
- Queue Count
- Active

### 2. Проверить разрешения (опционально)

Если поля не видны для всех пользователей:
1. **Settings** → **Customization** → **Modules** → **Contacts** → **Fields**
2. Для каждого поля → **Field Level Security**
3. Убедитесь, что для всех ролей:
   - ✅ **Visible** = Yes
   - ✅ **Editable** = Yes (если нужно)
