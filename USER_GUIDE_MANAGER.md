# 👔 Руководство для Менеджера: Управление агентами в Zoho CRM

## 📋 Что может делать менеджер

Как менеджер колл-центра, вы можете:
- ✅ Просматривать информацию обо всех агентах
- ✅ Редактировать информацию об агентах (если есть права)
- ✅ Создавать отчеты по агентам
- ✅ Фильтровать и анализировать данные
- ✅ Экспортировать данные агентов
- ✅ Отслеживать статусы и производительность

---

## 🔍 Поиск и фильтрация агентов

### Расширенный поиск

1. **Contacts** → **Advanced Search** (Расширенный поиск)
2. Добавьте условия:
   - **Agent ID** equals `6701`
   - **AND** Department = "Call Center"
   - **AND** Tikal Status = "Online"
3. Нажмите **Search**

### Сохраненные фильтры

Создайте часто используемые фильтры:

1. Настройте фильтр (например, Department = "Call Center")
2. Нажмите **"Save Filter"**
3. Назовите: **"Active Call Center Agents"**
4. Теперь можно быстро переключаться на этот фильтр

**Полезные фильтры:**
- "All Call Center Agents" - все агенты
- "Online Agents" - только онлайн агенты
- "Agents in Queue 1155" - агенты в определенной очереди

---

## 📊 Просмотр и редактирование агентов

### Просмотр информации

1. Найдите агента (поиск или фильтр)
2. **Кликните на контакт**
3. Просмотрите все поля:
   - Agent ID, Extension, Status
   - Queues, Queue Count
   - Контактная информация

### Редактирование информации

Если у вас есть права на редактирование:

1. Откройте контакт агента
2. Нажмите **"Edit"** (Редактировать)
3. Измените нужные поля:
   - Можно обновить Extension
   - Можно изменить Status (если нужно)
   - Можно добавить/изменить Email, Phone
4. Нажмите **"Save"**

**⚠️ Важно:** Статусы агентов обычно управляются через систему Tikal, а не через Zoho.

---

## 📈 Создание отчетов

### Отчет 1: Список всех агентов

1. **Reports** → **Create Report**
2. Выберите модуль: **Contacts**
3. Добавьте колонки:
   - First Name, Last Name
   - Agent ID
   - Extension
   - Tikal Status
   - Queues
   - Queue Count
4. Добавьте фильтр: **Department = "Call Center"**
5. **Save Report** → назовите "Call Center Agents List"

### Отчет 2: Агенты по статусам

1. Создайте отчет (см. выше)
2. Добавьте группировку: **Tikal Status**
3. Добавьте подсчет: **Count of Contacts**
4. **Save Report** → "Agents by Status"

### Отчет 3: Агенты по очередям

1. Создайте отчет
2. Добавьте группировку: **Queues**
3. Добавьте подсчет: **Count of Contacts**
4. **Save Report** → "Agents by Queues"

## 📤 Экспорт данных

### Экспорт списка агентов

1. Примените нужный фильтр (например, Department = "Call Center")
2. Выберите все контакты (чекбокс вверху)
3. **Actions** → **Export**
4. Выберите формат: **CSV** или **Excel**
5. Выберите поля для экспорта
6. **Export**

**Результат:** Файл со списком агентов для анализа

---

## 🔄 Обновление данных агентов

### Вариант 1: Обновление через импорт

1. Попросите администратора получить свежие данные из Tikal
2. Администратор создаст CSV файл
3. **Contacts** → **Import**
4. Загрузите файл
5. Выберите: **"Update existing records"**
6. Сопоставьте поля → **Import**

### Вариант 2: Ручное обновление

1. Найдите агента
2. Откройте контакт → **Edit**
3. Обновите нужные поля
4. **Save**

---

## 📊 Анализ данных

### Просмотр статистики

1. Используйте отчеты (см. выше)
2. Или создайте дашборд:
   - **Dashboards** → **Create Dashboard**
   - Добавьте виджеты:
     - Количество агентов
     - Агенты по статусам
     - Агенты по очередям

### Фильтрация для анализа

**Примеры фильтров:**

1. **Только активные агенты:**
   - Active = Yes
   - AND Department = "Call Center"

2. **Агенты в определенной очереди:**
   - Queues contains "1155"
   - AND Department = "Call Center"

3. **Онлайн агенты:**
   - Tikal Status = "Online"
   - AND Department = "Call Center"

## 👥 Управление командой

### Просмотр команды

1. Создайте фильтр: **Department = "Call Center"**
2. Сохраните как "My Team"
3. Используйте для быстрого доступа к команде

### Отслеживание статусов

1. Создайте представление (View) с колонками:
   - Agent ID
   - Extension
   - Tikal Status
   - Queues
2. Сохраните как "Team Status"
3. Используйте для мониторинга команды

---

## 🔧 Настройка представлений

### Создание кастомного представления

1. В модуле **Contacts** настройте нужные колонки
2. Примените нужные фильтры
3. Нажмите **"Save View"** или **"Save as View"**
4. Назовите представление (например, "Call Center Agents")
5. Теперь можно быстро переключаться на это представление

**Рекомендуемые колонки:**
- Contact Name
- Agent ID
- Extension
- Tikal Status
- Queues
- Queue Count
- Active

## 🆘 Решение проблем

### Проблема: Не вижу всех агентов

**Решение:**
- Проверьте фильтры - возможно, активен фильтр, который скрывает агентов
- Убедитесь, что фильтр Department = "Call Center" применен
- Обратитесь к администратору для проверки прав доступа

### Проблема: Не могу редактировать агентов

**Решение:**
- Проверьте права доступа (обратитесь к администратору)
- Убедитесь, что контакт не заблокирован
- Попробуйте обновить страницу

### Проблема: Данные устарели

**Решение:**
- Попросите администратора обновить данные из Tikal
- Или обновите вручную через Edit

## 📞 Создание звонков для агентов

**Агенты могут создавать звонки напрямую из Zoho CRM!**

После настройки администратором:

1. Агенты могут нажать кнопку **"Позвонить"** в контакте
2. Звонок создается через Tikal API
3. Агент получает звонок в системе Tikal

**Требования:**
- В контакте заполнен Agent ID агента
- В контакте заполнен Phone клиента
- Агент онлайн в системе Tikal

**Настройка:** Попросите администратора настроить интеграцию (см. `ZOHO_CALL_INTEGRATION.md`)
