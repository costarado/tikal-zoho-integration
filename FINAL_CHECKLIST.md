**Результат:** ✅ / ❌

### Проверка 2: Кастомные поля видны

1. Откройте любой контакт агента (например, "Agent Agent 6701")
2. Нажмите **"Edit"**
3. Проверьте, что видны кастомные поля:
   - Agent ID

   - Tikal Status
   - Queues
   - Queue Count
   - Active

**Результат:** ✅ / ❌

### Проверка 3: Данные заполнены

1. В том же контакте проверьте, что поля заполнены:

   - Queues = должен быть список очередей
   - Queue Count = должно быть число

**Результат:** ✅ / ❌

### Проверка 4: Поиск работает

1. В модуле **Contacts** используйте поиск
2. Введите Agent ID (например, `6701`)
3. Должен найти контакт

**Результат:** ✅ / ❌

2. Найдите **"Agent ID"**
