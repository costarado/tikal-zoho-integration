# 📋 Руководство: Что происходит после импорта агентов в Zoho CRM

## 🔄 Что происходит после импорта

### 1. **Агенты становятся контактами**

После импорта CSV файла в Zoho CRM:

✅ **Агенты создаются как контакты** в модуле **Contacts**
- Каждый агент = один контакт
- Все поля из CSV импортируются
- Agent ID сохраняется в кастомном поле или Description

✅ **Автоматическая обработка**
- Zoho проверяет дубликаты
- Создает записи для новых агентов
- Обновляет существующие (если настроено)

✅ **Доступность данных**
- Агенты видны в списке контактов
- Можно искать по имени, Agent ID, Extension
- Можно фильтровать по Department, Status, Queues

### 2. **Структура данных в Zoho**

```
Contacts Module
├── Agent 6701
│   ├── First Name: Agent
│   ├── Last Name: 6701
│   ├── Phone: [extension]
│   ├── Title: Call Center Agent
│   ├── Department: Call Center
│   ├── Description: [Agent ID, Extension, Status, Queues]
│   └── Custom Fields: Agent ID, Extension, Status, Queues
├── Agent 6702
└── ...
```

## 🎯 Как "активировать" агентов в Zoho

### ⚠️ Важно: Два типа "активации"

#### 1. **Активация в Tikal (Call Center)**
- Это управление через **Tikal API**
- Агенты активируются в системе Tikal
- Не связано напрямую с Zoho

**Как активировать в Tikal:**
```python
from tikal_client.tikal_client_v2 import TikalClientV2
from config import TIKAL_CONFIG

client = TikalClientV2(
    base_url=TIKAL_CONFIG['base_url'],
    api_key=TIKAL_CONFIG['api_key']
)

# Логин агента (активация)
client.agents.login(agent_id='6701', ag_exten='2012')

# Установка статуса
client.agents.set_state(agent_id='6701', state='ready')

# Назначение в очередь
client.agents.assign(agent_id='6701', queue_id='1005')
```

#### 2. **Активация в Zoho CRM**
- Это настройка контактов в Zoho
- Не влияет на работу в Tikal
- Используется для организации данных в CRM

**Как активировать в Zoho:**

**Вариант A: Через статус контакта**
1. Откройте модуль **Contacts**
2. Найдите агента
3. Добавьте кастомное поле **"Status"** или используйте существующее
4. Установите статус: "Active", "Online", "Ready"

**Вариант B: Через теги/группы**
1. Создайте группу **"Active Agents"**
2. Добавьте активных агентов в группу
3. Используйте для фильтрации и отчетов

**Вариант C: Через кастомные поля**
1. Создайте кастомное поле **"Is Active"** (Checkbox)
2. Отметьте активных агентов
3. Используйте для фильтрации

**Вариант D: Через Workflow Rules**
1. Настройте автоматическое обновление статуса
2. Синхронизируйте с Tikal API (требует дополнительной интеграции)

## 🚀 Настройка полной интеграции

### Шаг 1: Создание кастомных полей в Zoho

1. **Settings** → **Customization** → **Modules** → **Contacts**
2. Создайте поля:
   - **Agent ID** (Text, 50 символов)
   - **Extension** (Text, 20 символов)
   - **Tikal Status** (Picklist: Online, Offline, Ready, Busy)
   - **Queues** (Multi-Select Picklist)
   - **Is Active** (Checkbox)
   - **Last Sync** (DateTime)

### Шаг 2: Настройка синхронизации

**Вариант A: Ручная синхронизация**
```bash
# Запускайте регулярно для обновления данных
python get_active_agents_only.py
# Импортируйте обновленный CSV в Zoho
```

**Вариант B: Автоматическая синхронизация (требует разработки)**
```python
# Пример скрипта для синхронизации
from zoho_api import ZohoCRM
from tikal_client.tikal_client_v2 import TikalClientV2

# Получаем агентов из Tikal
tikal_agents = get_agents_from_tikal()

# Обновляем в Zoho
zoho = ZohoCRM(api_key='...')
for agent in tikal_agents:
    zoho.update_contact(
        agent_id=agent['id'],
        status=agent['status'],
        queues=agent['queues']
    )
```

### Шаг 3: Настройка Workflow Rules

1. **Settings** → **Automation** → **Workflow Rules**
2. Создайте правила:
   - При изменении статуса агента → отправка уведомления
   - При назначении в очередь → обновление поля Queues
   - При создании лида → автоматическое назначение агента

### Шаг 4: Настройка отчетов

1. **Reports** → **Create Report** → **Contacts**
2. Создайте отчеты:
   - Список активных агентов
   - Агенты по очередям
   - Статистика по статусам
   - Производительность агентов

## ⚙️ Автоматизация процессов

### Workflow Rule 1: Обновление статуса

```
Trigger: Contact Updated
Condition: Tikal Status changed
Action: Send Email to Manager
```

### Workflow Rule 2: Назначение лида

```
Trigger: Lead Created
Condition: Lead Source = "Tikal Call Center"
Action: Assign to Agent from Queue 1005
```

### Workflow Rule 3: Уведомление о звонке

```
Trigger: Call Completed (если настроен Calls модуль)
Condition: Agent ID matches Contact
Action: Update Contact Last Call Date
```
