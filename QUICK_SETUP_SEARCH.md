# 🔍 Быстрая настройка поиска для кастомных полей

## ⏱️ Время: ~5 минут

---

## 📋 Шаг 1: Откройте настройки полей

1. Войдите в **Zoho CRM**
2. Нажмите **⚙️ Settings** (Настройки)
3. Перейдите: **Customization** → **Modules** → **Contacts** → **Fields**

---

## 📋 Шаг 2: Включите поиск для каждого поля

Для каждого из 6 полей выполните:

### Поле 1: Agent ID
1. Найдите **"Agent ID"** в списке полей
2. **Нажмите на поле** для редактирования
3. Найдите опцию **"Searchable"** (Доступно для поиска)
4. **Включите** галочку ✅
5. Нажмите **"Save"**

### Поле 2: Extension
1. Найдите **"Extension"**
2. Включите **"Searchable"** ✅
3. **Save**

### Поле 3: Tikal Status
1. Найдите **"Tikal Status"**
2. Включите **"Searchable"** ✅
3. **Save**

### Поле 4: Queues
1. Найдите **"Queues"**
2. Включите **"Searchable"** ✅
3. **Save**

### Поле 5: Queue Count
1. Найдите **"Queue Count"** (может отображаться как "Queue_ Count")
2. Включите **"Searchable"** ✅
3. **Save**

### Поле 6: Active
1. Найдите **"Active"**
2. Включите **"Searchable"** ✅
3. **Save**

---

## ✅ Проверка

После настройки всех полей:

1. Перейдите в модуль **Contacts**
2. Попробуйте найти контакт по **Agent ID**:
   - В строке поиска введите Agent ID (например, `6701`)
   - Должен найти контакт

3. Или используйте фильтр:
   - **Filter By Fields** → **Agent ID** → введите значение
   - Должен найти контакт

---

## 🎯 Готово!

После включения поиска для всех полей:
- ✅ Поиск будет работать по всем кастомным полям
- ✅ Фильтры будут работать корректно
- ✅ Можно будет быстро находить агентов по Agent ID

**Время настройки:** ~5 минут (менее 1 минуты на поле)

---

## 💡 Дополнительно: Проверка разрешений

Если поля не видны для всех пользователей:

1. Для каждого поля → **Field Level Security**
2. Для всех ролей установите:
   - ✅ **Visible** = Yes
   - ✅ **Editable** = Yes (если нужно редактирование)
