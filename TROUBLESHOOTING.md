# Решение проблем

## Проблема: Ошибка подключения к серверу

### Симптомы
```
TikalConnectionError: Не удалось подключиться к серверу...
WinError 10061: No connection could be made because the target machine actively refused it
```

### Решения

#### 1. Проверка подключения
Запустите утилиту диагностики:
```bash
python check_connection.py
```

#### 2. Проверка URL
Убедитесь, что URL в `config.py` правильный:
- Проверьте, что используется правильный протокол (http/https)
- Проверьте порт (возможно нужен другой порт, например 8080, 8443)
- Если сервер в локальной сети, используйте внутренний IP

#### 3. Проверка доступности сервера
```bash
# Проверка DNS
ping arielsip.com

# Проверка порта (Windows)
telnet arielsip.com 443

# Проверка порта (Linux/Mac)
nc -zv arielsip.com 443
```

#### 4. Альтернативные варианты URL

Если стандартный URL не работает, попробуйте:

```python
# В config.py измените base_url на один из вариантов:
TIKAL_CONFIG = {
    'base_url': 'http://arielsip.com',  # HTTP вместо HTTPS
    # или
    'base_url': 'https://arielsip.com:8443',  # Другой порт
    # или
    'base_url': 'http://192.168.1.100:8080',  # Внутренний IP
}
```

#### 5. Проблемы с SSL сертификатом

Если используется самоподписанный сертификат, добавьте в код:

```python
import ssl
import urllib3
urllib3.disable_warnings(urllib3.exceptions.InsecureRequestWarning)

# В client.py добавьте verify=False в requests
response = self._session.request(
    ...,
    verify=False  # Только для разработки!
)
```

⚠️ **Внимание**: Отключение проверки SSL небезопасно для production!

#### 6. Файрвол/Сеть

- Проверьте настройки файрвола Windows
- Убедитесь, что порт не заблокирован корпоративным файрволом
- Проверьте настройки прокси (если используется)

#### 7. Локальный сервер

Если API работает на локальной машине:
- Используйте `http://localhost:port` или `http://127.0.0.1:port`
- Проверьте, что сервер действительно запущен
- Проверьте логи сервера

## Проблема: Ошибка аутентификации

### Симптомы
```
TikalAuthenticationError: Ошибка аутентификации: 401
```

### Решения

1. **Проверьте токены** в `config.py`
2. **Обновите токены** - они могли истечь
3. **Выполните повторный вход**:
   ```python
   client = TikalClient(
       base_url='...',
       username='admin',
       password='Ariel2023!'
   )
   ```

## Проблема: Таймаут запросов

### Симптомы
```
TikalConnectionError: Превышено время ожидания запроса
```

### Решения

1. **Увеличьте timeout**:
   ```python
   client = TikalClient(
       base_url='...',
       timeout=60  # Увеличьте до 60 секунд
   )
   ```

2. **Проверьте скорость сети**
3. **Проверьте нагрузку на сервер**

## Проблема: Неправильный формат ответа

### Симптомы
```
ValueError: Expecting value: line 1 column 1 (char 0)
```

### Решения

1. Проверьте, что endpoint возвращает JSON
2. Проверьте логи сервера
3. Добавьте обработку не-JSON ответов в код
